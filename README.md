Ecommerce Sales Analysis

Project Description

Ecommerce Sales Analysis is a data analytics project developed using Python. It analyzes e-commerce sales data to identify sales trends, product performance, revenue and business insights.

Technologies Used

- Python
- Pandas
- Matplotlib
- Tkinter

Project Features

- Sales data analysis
- Data cleaning and preprocessing
- Revenue calculation
- Product performance analysis
- Sales visualization using graphs
- Excel sales report generation
- Graphical User Interface (GUI)

Project Files

- analysis.py – Performs sales data analysis.
- gui.py – Provides the graphical user interface.
- sales_data.csv – Original sales dataset.
- cleaned_sales_data.csv – Cleaned dataset.
- sales_report.xlsx – Generated sales report.
- dashboard.png – Sales dashboard visualization.

How to Run

1. Install Python.
2. Install the required libraries:
   pip install pandas matplotlib openpyxl
3. Run the analysis.py file.
4. Run gui.py to open the graphical interface.

Objective

The main objective is to analyze e-commerce sales data and present meaningful business insights through data analysis and visualization.

Conclusion

This project demonstrates the use of Python for data analysis, data visualization and generating useful business reports.
